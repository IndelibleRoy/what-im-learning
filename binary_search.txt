### Binary Search

Binary Search is a much more efficient searching algorithm than Linear Search. 
Instead of checking every element one by one, it repeatedly divides the search
space into half.

Why Binary Search?
Suppose we have 1000 elements:
Linear Search → Up to 1000 comparisons
Binary Search → Only about 10 comparisons (log₂(1000) ≈ 10)
This makes Binary Search significantly faster for large datasets.
Important: Binary Search works only on a sorted array.

NOTE : Binary Search works by repeatedly halving the search space.
Instead of checking every element, it eliminates half of the remaining 
elements after each comparison, resulting in a time complexity of O(log n). 
This makes it one of the most efficient searching algorithms for sorted data.

The simplest mental model is:

Look at the middle element.
If the target is bigger, throw away the left half.
If the target is smaller, throw away the right half.
Repeat until found or the search space becomes empty.

Why Binary Search Is Fast

Each comparison cuts the search space in half:
            1000 elements
            ↓
            500
            ↓
            250
            ↓
            125
            ↓
            62
            ↓
            31
            ↓
            15
            ↓
            7
            ↓
            3
            ↓
            1

That's why binary search runs in O(log n) time instead of O(n) like a linear search.
